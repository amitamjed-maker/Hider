# App Hider

একটা অ্যাপ যেটা দিয়ে তুমি যেকোনো অ্যাপ হাইড করতে পারবে — হাইড করলে ঐ অ্যাপের নেট কানেকশন ব্লক হয়ে যাবে এবং অ্যাপটা খোলার চেষ্টা করলেই সাথে সাথে হোমে ফিরিয়ে দেওয়া হবে (ফলে ব্যাটারি/ডাটা ইউজও বন্ধ থাকে)। App Hider-এর নিজের কোনো হোমস্ক্রিন আইকন নেই।

## অ্যাপ খোলার উপায়
ফোনের **ডায়ালারে** গিয়ে এই কোডটা টাইপ করো:

```
*#*#3330#*#*
```

সাথে সাথে App Hider খুলে যাবে।

## প্রথমবার সেটআপ (দুটো ধাপ, একবারই করতে হবে)
1. অ্যাপে ঢুকে যে অ্যাপগুলো হাইড করতে চাও, সেগুলোর পাশের চেকবক্স টিক দাও।
2. দুইটা বাটনে চাপো:
   - **"নেট ব্লক চালু করো"** — এটা চাপলে Android একটা VPN পারমিশন চাইবে, "OK" দিয়ে দিও। এরপর হাইড করা অ্যাপগুলোর ইন্টারনেট বন্ধ হয়ে যাবে।
   - **"Accessibility অন করো"** — এটা Settings-এ নিয়ে যাবে, সেখানে তালিকায় "App Hider" খুঁজে অন করে দিও। এটা অন থাকলেই হাইড করা অ্যাপ খোলার চেষ্টা করলে সাথে সাথে হোমে চলে আসবে।

এই দুটো একবার অন করে দিলে ফোন রিস্টার্ট দিলেও নিজে থেকে আবার চালু হয়ে যাবে।

## এই অ্যাপ যা করে
- ✅ হাইড করা অ্যাপের ইন্টারনেট (ওয়াইফাই + মোবাইল ডাটা) পুরোপুরি বন্ধ করে দেয়
- ✅ হাইড করা অ্যাপ খুলতেই দেয় না — তাই ব্যাটারি/ডাটা/জিপিএস কোনো কিছুই খরচ হয় না
- ✅ নিজের কোনো আইকন নেই, শুধু ডায়াল কোড দিয়ে খোলা যায়
- ✅ রুট (root) লাগে না

## সীমাবদ্ধতা (Android-এর নিয়মের কারণে)
- GPS/লোকেশন নির্দিষ্ট একটা অ্যাপের জন্য আলাদাভাবে বন্ধ করা Android পারমিশন দেয় না। যেহেতু অ্যাপটা খুলতেই দেওয়া হয় না, বাস্তবে ঐ অ্যাপ লোকেশনও ইউজ করতে পারবে না — তবে এটা সিস্টেম লেভেলের GPS টগল না।
- Accessibility সার্ভিস অন করাটা Android নিজে থেকে করতে দেয় না (নিরাপত্তার কারণে) — এটা তোমাকে একবার ম্যানুয়ালি Settings থেকে অন করতে হবে।
- কিছু ফোনে (Vivo, Xiaomi ইত্যাদি) ব্যাটারি সেভার নিজের থেকেই background অ্যাপ বন্ধ করে দেয় — তাই App Hider-কে "No restriction" / "Autostart" লিস্টে রাখতে হতে পারে, নাহলে ও নিজেই বন্ধ হয়ে যেতে পারে।

## বিল্ড করার উপায় (Termux / GitHub Actions থেকে)
তোমার যেহেতু ল্যাপটপ নেই, এই প্রজেক্টটা GitHub-এ পুশ করলেই `.github/workflows/build.yml` অটোমেটিক APK বানিয়ে দেবে:

1. এই পুরো ফোল্ডারটা একটা নতুন GitHub রিপোতে পুশ করো।
2. GitHub-এর "Actions" ট্যাবে গিয়ে বিল্ড শেষ হওয়া পর্যন্ত অপেক্ষা করো।
3. বিল্ড শেষ হলে "Artifacts" সেকশন থেকে `app-hider-debug-apk` ডাউনলোড করো — ওটার ভেতরেই `app-debug.apk` থাকবে।
4. APK ফোনে ইনস্টল করো (Unknown sources অন করতে হতে পারে)।

Termux থেকেও চাইলে সরাসরি বিল্ড করা যায়:
```
pkg install git openjdk-17 -y
git clone <তোমার-রিপো-লিংক>
cd AppHider
gradle assembleDebug
```
(Termux-এ gradle/android SDK সেটআপ একটু ঝামেলার, তাই GitHub Actions পদ্ধতিটাই সহজ ও নির্ভরযোগ্য।)
